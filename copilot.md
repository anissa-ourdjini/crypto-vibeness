Objectif
Implémenter un système de chat sécurisé en Python via prompts itératifs à un agent IA.
Concepts crypto : 
hash, sel, chiffrement symétrique/asymétrique, E2EE, signatures.


Étapes Clés
YOLO : Multi-clients, rooms/mdp, couleurs, logs.

Auth : md5 base64 → this_is_safe.txt.

Hacker FR : hashcat ?u?u?l?l?u?u?s, bcrypt:cost:salt:hash.

Symétrique : Clés dérivées, TEA/sodium.

Asymétrique : .pub/.priv, échange session.

E2EE : Annuaire pub, session/paire, sign/verify.
